# Self-hosted typefaces

All three are variable fonts, latin subset, fetched once from Google Fonts on
2026-09-06 and served from this folder so that builds never depend on a CDN.

| file | family | license |
| --- | --- | --- |
| `unbounded.woff2` | Unbounded (NaN / Google Fonts) | SIL Open Font License 1.1 |
| `archivo.woff2` | Archivo (Omnibus-Type / Google Fonts) | SIL Open Font License 1.1 |
| `geist-mono.woff2` | Geist Mono (Vercel) | SIL Open Font License 1.1 |

The OFL permits bundling and self-hosting; the fonts are not sold on their own.
